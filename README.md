# homebrew-infernet

Official Homebrew tap for the [Infernet Protocol](https://github.com/profullstack/infernet-protocol) CLI.

## Install

```bash
brew tap profullstack/infernet
brew install infernet
```

## How the tap gets updated

The formula at `Formula/infernet.rb` is generated by the release pipeline in the main [profullstack/infernet-protocol](https://github.com/profullstack/infernet-protocol) repo (see `.github/workflows/release.yml`). On each tagged release, `tooling/dist/homebrew/update-formula.mjs` downloads the new npm tarball, computes its sha256, and attaches the pinned formula to the GitHub Release. A maintainer copies it here and pushes.
